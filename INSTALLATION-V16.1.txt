LOGANATOR SHOP V16.1 — PREMIUM PLUS (ÉDITION AMÉLIORÉE)

INSTALLATION
1. Décompresse cette archive.
2. Remplace les fichiers du site par ceux de cette archive (conserve les mêmes noms de fichiers).
3. Recharge le site avec Ctrl + F5.
4. Connecte-toi avec un compte Premium autorisé et ouvre le Centre de contrôle LOGANATOR.

FONCTIONS PREMIUM
- Dashboard et alertes de stock faible.
- Gestion des produits, duplication, édition du stock et téléchargement individuel d’image.
- Téléchargement groupé des images dans une archive ZIP (nécessite une connexion internet pour charger JSZip; les images externes doivent autoriser CORS).
- Centre de promotions local.
- Personnalisation de contenu avec brouillon et prévisualisation.
- Sauvegarde/restauration JSON locale.
- Exports catalogue, stocks et rapports CSV.
- Rapport imprimable, enregistrable en PDF depuis la boîte d’impression du navigateur.

ACCÈS PREMIUM
Les comptes dans la liste Premium intégrée sont reconnus automatiquement. Les comptes présents dans la table Supabase `premium_members` sont également reconnus lorsque la vérification de la table est disponible.

LIMITES IMPORTANTES
Les modifications locales, promotions locales, sauvegardes et commandes locales sont enregistrées dans le navigateur courant et ne sont pas automatiquement partagées entre les appareils. L’export ZIP récupère les images accessibles par le navigateur; des images hébergées sur un domaine sans CORS peuvent être ignorées. Les restrictions d’accès d’un site public ne peuvent pas être sécurisées uniquement par JavaScript côté navigateur; une protection côté serveur/RLS reste nécessaire pour des privilèges véritablement inviolables.
