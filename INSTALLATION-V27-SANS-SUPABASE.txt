INSTALLATION LOGANATOR V27 — PHP + JSON

1. Hébergement compatible PHP 8+.
2. Envoyer tous les fichiers à la racine du site.
3. Ouvrir setup.php une seule fois pour créer le compte Premium.
4. Supprimer ou protéger setup.php après création du compte.
5. Vérifier que data/ et uploads/products/ sont accessibles en écriture par PHP.

MAINTENANCE RÉELLE

Dans Premium > Control Center > Paramètres :
- Mode maintenance = Activé
- cliquer sur Enregistrer

Le réglage est écrit dans data/settings.json.
Le fichier index.php vérifie ce réglage AVANT d'envoyer la boutique.
Un visiteur non connecté reçoit une réponse HTTP 503 et uniquement le message :
« Le site est en cours de maintenance ».

Un compte Premium déjà connecté conserve l'accès administratif afin de pouvoir désactiver la maintenance.

IMPORTANT : ne pas remplacer index.php par un index.html, sinon le contrôle de maintenance côté serveur ne pourra pas s'exécuter.
